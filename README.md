### Selected work

| Project | What it explores |
| --- | --- |
| [**Luna**](https://github.com/aoweichenn/luna) | A self-hosting systems language. Its compiler, assembler, and linker are written in Luna. |
| [**ash**](https://github.com/aoweichenn/ash) | A C++20 agent runtime that records real runs and replays them offline with deterministic verification. |
| [**x86-64 OS Lab**](https://github.com/aoweichenn/os) | An operating system built from firmware and bootloader through kernel, user space, and file system. |
| [**Aurex**](https://github.com/aoweichenn/aurex) | A C++20 systems-language compiler with a typed IR and LLVM lowering. |
